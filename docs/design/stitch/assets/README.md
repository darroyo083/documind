# Stitch assets

- design-system.json is the structured Design System response retrieved from Stitch.
- stitch-placeholder-300x300.svg is the placeholder asset referenced by generated Stitch HTML.
- hosted-1.jpg through hosted-9.jpg are the image assets referenced by the generated Stitch HTML and downloaded from the exact hosted URLs returned in that HTML.

The generated HTML remains secondary reference material. These assets should not be promoted into production until the implementation phase confirms that they represent real DocuMind product content rather than Stitch sample data.
